# Contributing to Channel Studio

Thank you for your interest in contributing! This project follows a simple, steady approach — keep things smooth, practical, and manageable.

## How to Contribute

1. **Fork** the repository
2. **Create a branch** from `main` with a descriptive name
3. **Make your changes** — keep them focused and minimal
4. **Test locally** — run `npm run build` and `npm run typecheck` before submitting
5. **Open a pull request** with a clear description of what changed and why

## Code Style

- Match the existing conventions in the codebase
- Use TypeScript types for all function parameters
- Prefer editing existing files over creating new ones
- Keep files at a manageable size
- Use the `@/` path alias for imports from `src/`

## Commit Messages

Keep commit messages short and descriptive:

```
Add fallback recovery checks
Fix workflow stage ordering
Update Instagram pilot prerequisites
```

## Working Rule

> Prefer steady expansion over fast expansion. Stop and simplify if something introduces unnecessary pressure.

## Reporting Issues

Open an issue with a clear title and description. Include steps to reproduce if it's a bug.

Thanks for helping make Channel Studio better!
